# ICP-Radar: Hydraulische Antriebstechnik, Starker Fit

Interaktives Dashboard der 36 Hersteller hydraulischer Antriebstechnik in Deutschland mit ICP-Note A (Starker Fit): Note, Punkte, 24 Kriterien mit Begründung, Ansprechpartner mit LinkedIn-Profil und Sales-Navigator-Suchlink.

Die Seite ist eine einzelne HTML-Datei (`index.html`), alle Daten sind eingebettet. Per "CSV laden" lässt sich jede andere ICP-Bewertungsliste mit derselben Spaltenstruktur im Browser anzeigen; dabei werden keine Daten hochgeladen.

Stand der Daten: 31. August 2026.
